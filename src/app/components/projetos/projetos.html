O Santo Restauro é uma aplicação especializada na gestão de acervos de museus, desenvolvida em Python com o framework Django para garantir máxima segurança e escalabilidade. A plataforma centraliza o controle das coleções, permitindo o cadastro detalhado, a edição de metadados históricos e a visualização organizada de cada item, unindo a robustez técnica da linguagem à necessidade de preservação e organização do patrimônio cultural. A Master Car é um sistema especializado no gerenciamento de vendas para concessionárias, desenvolvido com a robustez da linguagem Java e uma interface intuitiva em HTML e CSS. A plataforma centraliza todo o fluxo comercial, desde o controle de inventário de veículos até a finalização de propostas, utilizando a tipagem forte do Java para garantir transações seguras e um design responsivo que agiliza o atendimento ao cliente e a organização operacional da loja. O Finny é um ecossistema de gestão financeira focado no controle rigoroso de gastos e na visualização estratégica de dados através de dashboards interativos. Desenvolvido com o trio fundamental do ecossistema web — HTML, CSS e JavaScript — o sistema transforma registros de despesas em insights visuais em tempo real, utilizando a manipulação dinâmica de elementos via JavaScript para oferecer uma interface ágil, responsiva e totalmente orientada à saúde financeira do usuário.
